# Pesquisas técnicas

Estudos que ajudam a decidir **como** fazer algo no jogo. Um arquivo por assunto.

| Data | Pesquisa |
| --- | --- |
| 2026-11-22 | [Melhorias para o Dojo do Foco](2026-11-22-melhorias-do-dojo.md): concorrentes, ciência, opinião de usuários, tendências, interface e parte técnica. As notas de cada fonte estão em [2026-11-22-melhorias-do-dojo/](2026-11-22-melhorias-do-dojo/) |

Bons temas:

- Bibliotecas e APIs usadas ou candidatas (three.js, Open-Meteo, Web Audio)
- Desempenho no celular e em computadores fracos
- Acessibilidade (contraste, leitor de tela, teclado)
- Testes automatizados para um jogo de um arquivo só
- Formas de guardar o progresso (navegador, Obsidian, nuvem)

Modelo de arquivo, `pesquisas/AAAA-MM-DD-assunto.md`:

```
# Assunto
Pergunta: o que eu quero saber
Fontes: links
O que descobri: ...
Conclusão: ...
```

> As ideias de jogo (reinos, personagens, mecânicas) ficam em `../dojo-do-foco/`, não aqui.
